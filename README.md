# GameProgressionTrackerDB

This is a project built for the course at BTH called Database Systems DV1663. 

The project is made using Python to connect to an MySQL server which the user can execute their own queries on or queries that are built into the project and were made to fulfill the assignment requirements. 

The database dump is also available if one wants to easily test the application in their own server.

This project will be marked private as soon as grading is done!
